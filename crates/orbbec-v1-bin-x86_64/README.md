# orbbec-v1-bin-x86_64

Original precompiled Orbbec SDK **1.10.37** for `x86_64-unknown-linux-gnu`.
Consumed automatically by `orbbec-v1-sys`; this crate has no build-time downloads.
Only the matching architecture is compiled as a dependency.

Includes the four runtime libraries, SDK configuration, the original SDK license,
third-party license texts, upstream source snapshots, and SHA-256 provenance.
The SDK is for Orbbec products and retains its custom terms. The small Rust
packaging code is MIT licensed; the binaries are not relicensed as MIT.

See THIRD_PARTY.md for source provenance and the unresolved vendor build details.
This package's source snapshots do not establish exact correspondence to the
vendor-built libraries. Public release readiness is recorded in the repository's
`docs/distribution.md`.
